# Story E21S13: Atomic cutover commit — delete legacy tournament stack + mechanical FQN rewrite of 6 consumer contexts + wire new beans

## User Story

**As a** reviewer of the Wave-2 Track-3 final step,
**I want** the tournament-scoped legacy classes (under `de.vvwt.tm.domain.*` and `de.vvwt.tm.infrastructure.web.*`), the two legacy tenant-bridges (`TenantContext`, `TenantScopedRepository`), `DeviceLimitConfig`, and the `SpikeTestController` deleted in one atomic commit on `staging`, the ~80 import lines across six still-legacy consumer contexts mechanically rewritten from `de.vvwt.tm.domain.X` → `de.vvwt.tm.tournament[.internal].X` per DEC-32, and two pre-cutover smoke-ITs (`TournamentCutoverSmokeIT`, `TournamentCrossContextSmokeIT`) green,
**so that** the `tournament` context is fully reconstructed, the DEC-21 atomic-cutover protocol is exercised end-to-end for a hub context with six live consumers, DEC-32's mechanical-FQN-rewrite protocol is exercised for the first time under governance, and nothing in the codebase references the pre-reconstruction tournament stack.
