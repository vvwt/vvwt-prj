# Story E33S03: Extract `DeviceService` public interface + `DefaultDeviceService` impl; relocate 2 Device exceptions to `tournament.exceptions`

## User Story

**As a** maintainer of the `de.vvwt.tm.tournament` Modulith module post-E21,
**I want** `DeviceService` exposed as a public interface in
`de.vvwt.tm.tournament.*` root (with `DefaultDeviceService` in
`.internal`, `@Service("tmDeviceService")` preserved) AND
`DeviceLimitExceededException` + `DisplayDeviceLimitExceededException`
relocated from `tournament.internal.*` to the existing
`tournament.exceptions.*` named-interface sub-package,
**so that** E22's `de.vvwt.tm.web.DeviceController` +
`DeviceAdminController` migration per DEC-40 Clause D can consume the
interface + catch the exceptions via `tournament::exceptions` without
reaching into `tournament.internal.*`.

---

## Context

`DeviceService` has 2 controller consumers currently in the same module
(`DeviceController:63 @Qualifier("tmDeviceService")`, `DeviceAdminController:49
@Qualifier("tmDeviceService")`). Additionally, `DeviceController`
imports 2 device-related exceptions from `tournament.internal` —
`DeviceLimitExceededException` + `DisplayDeviceLimitExceededException`
— and 1 response body `DeviceLimitErrorResponse` (the last is OUT of
E33 scope per DEC-40 Clause B; stays internal until E22 relocates to
`web.internal.dto.*`).

Classification: Q-1b pure refactor. No RED-first required. All existing
`DeviceServiceTest` + `DeviceControllerIT/SliceTest` + `DeviceAdminControllerIT/SliceTest`
assertions remain GREEN.
