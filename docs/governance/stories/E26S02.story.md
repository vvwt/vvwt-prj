Per user choice 2026-04-27 Frage 1: **option A** — audio is a public sub-package of timer at `de.vvwt.tm.timer.audio.*`, NOT a separate Modulith module.

No DAO classes; no DAO IT obligations. Confirm at delivery.

Legacy naming-canon violation: `AudioStorageServiceImpl` (legacy at `domain/audio/AudioStorageServiceImpl.java`) violates DEC-35 (`Default*` naming canon, no `Impl` suffix). Fresh authoring at E26S02 corrects to `DefaultAudioStorageService`.

**Pattern A consolidation per DEC-40 §2026-04-27 Clarification:** Legacy `de.vvwt.tm.infrastructure.web.audio.AudioMetadataResponse.java` is empirically a 1:1 wrapper of `de.vvwt.tm.domain.audio.AudioFileMetadata` — both records have identical 4-field shape `(AudioCategory category, String filename, long sizeBytes, Instant uploadedAt)` (verified at Discovery 2026-04-27 by reading both files); the legacy `AudioMetadataResponse.from(AudioFileMetadata)` static factory is a pass-through identity mapping. No Clause B (a)/(c)/(d) condition fires (no field omission, no cross-context aggregation, no field aliasing). Per Pattern A Decision Rule §289-296: the wire shape and the projection are the same shape → consolidate to ONE record at the bounded-context module root. E26S02 authors `de.vvwt.tm.timer.audio.AudioFileMetadata` ONLY; the legacy `AudioMetadataResponse` 1:1 wrapper is DELETED at S02 (not re-authored at S03; not re-authored at all). Service `AudioStorageService.list(UUID)` returns `List<AudioFileMetadata>` (was: `List<AudioFileMetadata>` per legacy too — preserved); controller (E26S03 `AudioController.list`) returns `List<AudioFileMetadata>` directly to JSON (was: `List<AudioMetadataResponse>` with mapping — Pattern A simplifies away the redundant mapping step). Service `AudioStorageService.upload(...)` continues returning `AudioFileMetadata` (preserved per legacy + audit (iv)).

This story authors the **timer.audio sub-package** (interface + impl + 5 supporting types incl. `AudioFileMetadata` Pattern A consolidated record). The timer-domain core (TimerDataService + 4 timer query-shape records) is E26S01 scope. Web-side controllers + cross-cutting edits + ITs are E26S03 scope (E26S03 authors NO web-tier DTOs per Pattern A). Cutover-housekeeping is E26S04 scope.
