# Implementation Report — E05S12

## Summary

Implemented auto-seed of N=teamCount empty team slots at tournament creation within the same
`@Transactional` boundary. Teams are labeled using `MessageSource` key `team.defaultLabel`
(German default "Mannschaft") with locale resolved from `tenant.language ?? "de"`.

Key deliverables:
- `DefaultTournamentService.createTournament()` extended with seed loop (N iterations of
  `teamRepository.save(team)`) within `@Transactional` scope
- `TeamRepository.deleteByTournamentId()` added (+ `DefaultTeamRepository` implementation)
  so that `deleteTournament()` can cascade-delete seeded teams before removing the tournament
  row (necessary due to `ON DELETE RESTRICT` FK on `team.tournament_id`)
- `messages.properties` updated with `team.defaultLabel=Mannschaft`
- Two new test files committed RED (DEC-22) then GREEN:
  - `DefaultTournamentServiceSeedTest` (white-box unit test, same package, DEC-36)
  - `TournamentSeedControllerIT` (web module IT, DEC-44 D1)
- Seven pre-existing ITs updated to account for N auto-seeded teams at creation
- `DraftControllerIT.sampleSection()` gameMode corrected from `"roundrobin"` to `"roundRobin"` —
  this latent bug was masked because previously no teams existed and match generation was skipped

## Design Decisions

- **Direct TeamRepository injection** into `DefaultTournamentService` — no boundary violation
  (both are in `tournament.internal`). Avoids `DefaultTeamService` call overhead (status
  checks, team-number uniqueness checks) that are unnecessary for controlled seeding.
- **Locale chain today-state**: `SELECT language FROM tenants` via existing `JdbcTemplate`.
  Fall back to `"de"` if null/blank. Future-binding C-13: tournament.language extends the chain.
- **`@Transactional` on `createTournament`**: any `DataAccessException` from team inserts rolls
  back both the tournament row and all previously-inserted team rows (AC-ERR-ATOMIC-ROLLBACK).
- **`deleteByTournamentId` before `deleteById`**: necessary consequence of seeding — the DB FK
  is `ON DELETE RESTRICT`. The E05S12 story required we clean up the seed rows on delete.

## Risks Realized

- **R1 (pre-existing IT breakage)**: Auto-seeding changed the observable state for 7 ITs that
  assumed an empty team list after tournament creation. All were updated with minimal scope
  changes (no new test logic introduced, only assertions and setup adapted).
- **Latent bug exposed**: `DraftControllerIT.sampleSection()` used `"roundrobin"` (lowercase)
  as the `gameMode`. This was never exercised because `participatingTeams` was always empty
  before E05S12. The bug was fixed as part of remediation.
