# Story E45S01: Pre-Reset — relocate `de.vvwt.tm.domain.activity.*` + `de.vvwt.tm.domain.repo.ActivityType*Repository` into `de.vvwt.tm.tournament.activity` sub-package (DEC-21 atomic-cutover; Flyway-deletion §step-3 N/A)

## User Story

**As a** Tournament Manager developer maintaining the Spring Modulith bounded-context layout,
**I want** the legacy `de.vvwt.tm.domain.activity.*` services and `de.vvwt.tm.domain.repo.ActivityType*Repository` DAOs relocated into `de.vvwt.tm.tournament.activity` as a proper sub-package of the `tournament` Modulith module,
**so that** the activity-types feature lives within its owning bounded context (tournament), satisfies `ApplicationModules.verify()`, and is positioned for the Wave-2 Big-Bang-Reset (E45S05) where the V13 `activity_types` schema lands in `tournament/V1`.

---

## Context

Brief O-3 surfaced this gap: DEC-39 D5 anticipated activity-types reconstruction
to land in a Wave-2 Track-3 epic, but no such epic was authored. The Java code
(ActivityType entity, ActivityTypeService + Default impl, ActivityAssignment*,
LapSchedule, FirstFreeRoundAssigner, AssignmentRule, ActivityTypeRepository,
ActivityTypeCrudRepository) sits in legacy top-level packages
`de.vvwt.tm.domain.activity.*` + `de.vvwt.tm.domain.repo` that pre-date the
Spring Modulith adoption (DEC-21). Without `package-info.java`, these packages
are not part of any Modulith bounded context.

E45S05's atomic SQL Reset places `activity_types` (V13) in `tournament/V1`. For
the schema-Java alignment to be coherent, the activity-types Java code must live
in `de.vvwt.tm.tournament.*` before S05 lands. S01 closes this gap as Pre-Reset
prep under DEC-21 atomic-cutover protocol — but with §step-3 (Flyway-deletion)
explicitly N/A: Flyway artefacts move only at S05.

Q-1a-vs-DEC-32 classification is deferred to story-authoring (Brief H-2 +
T-4): if existing tests on the relocated code are Spec-Anchored per DEC-41
classification (jqwik @Property / round-trip / external-spec citation / named
algebraic invariant), they survive as supplementary regression safety and the
relocation invokes DEC-32 mechanical FQN-rewrite (DEC-32 invocation count
becomes #2 = below the >2 re-examination trigger). If Snapshot-Driven, legacy
tests deleted, fresh Q-1a authored under DEC-22 Iron Law. The Discovery
implementation step produces a legacy-inventory artefact at delivery time.
