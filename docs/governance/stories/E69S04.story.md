# Story: Fix `build-image.sh:287` `update-custompios-paths` argument so FullPageOS `build_dist` finds `custompios_path`

## User Story

**As a** tournament operator,
**I want** `./build-image.sh` (delivered by E69S03) to invoke
`update-custompios-paths` with the argument the upstream FullPageOS contract
expects,
**so that** FullPageOS `build_dist` can read `${FullPageOS}/src/custompios_path`
and the Docker build phase proceeds — without the `/build_custom_os: not found`
failure that the first live operator-attestation (2026-05-27 19:02) exposed.

---

## Root Cause Analysis

Single defect in `vvwt-prj/pi-display/build-image.sh:287`:

```bash
"${WORK_DIR}/CustomPiOS/src/update-custompios-paths" "${WORK_DIR}/FullPageOS"
```

**Upstream contract** — `update-custompios-paths` source (CustomPiOS master,
verified at review time):

```bash
DEST=$PWD
if [ ! -z $1 ]; then
    DEST=$1
fi
DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
echo "${DIR}" > ${DEST}/custompios_path
```

With `$1 = ${WORK_DIR}/FullPageOS`, the script writes the symlink-helper file
at `${WORK_DIR}/FullPageOS/custompios_path`.

**Consumer** — FullPageOS `src/build_dist:4` (tag 0.14.0, verified at review
time):

```bash
DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
export DIST_PATH=${DIR}
export CUSTOM_PI_OS_PATH=$(<${DIR}/custompios_path)
```

`${DIR}` here is `dirname(build_dist) = ${WORK_DIR}/FullPageOS/src/`. The
consumer reads `${WORK_DIR}/FullPageOS/src/custompios_path` — one directory
level below where the producer wrote it.

**Mismatch** — `update-custompios-paths` wrote at
`${WORK_DIR}/FullPageOS/custompios_path`; `build_dist` reads at
`${WORK_DIR}/FullPageOS/src/custompios_path`. `$(<…)` returns empty for a
nonexistent file, so `CUSTOM_PI_OS_PATH=""`, and the next line
`${CUSTOM_PI_OS_PATH}/build_custom_os` resolves to `/build_custom_os` —
absolute path against `/`, not found, exit non-zero.

**Upstream canonical invocation** — FullPageOS README "Developing" section:

```
cd FullPageOS/src
../../CustomPiOS/src/update-custompios-paths
```

PWD = `FullPageOS/src/`, no `$1` argument, so DEST defaults to PWD =
`FullPageOS/src/`. `update-custompios-paths` writes
`${FullPageOS}/src/custompios_path` — exactly where `build_dist` reads.

**Fix** — change the `$1` argument on `build-image.sh:287` from
`"${WORK_DIR}/FullPageOS"` to `"${WORK_DIR}/FullPageOS/src"` so the produced
`custompios_path` lands at the location `build_dist` consumes.

**Why it slipped past E69S03** — E69S03 AC2's bats are fixture-based against a
mock FullPageOS-source-tree (per E69S03 O-8: Delivery has no Docker / sudo /
network-clone in `mvn verify`); the fixture-based assertions verify the
overlay-apply step against directory structure, not the
`update-custompios-paths` invocation. E69S03 AC5 operator-attestation runs
post-merge; the 2026-05-27 19:02 attempt is that first live attest, by
construction.
