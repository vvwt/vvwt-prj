# Story E33S05: Extract `DraftService` public interface + `DefaultDraftService` impl; relocate `DraftAlreadyAppliedException`

## User Story

**As a** maintainer of the `de.vvwt.tm.tournament` Modulith module post-E21,
**I want** `DraftService` exposed as a public interface in
`de.vvwt.tm.tournament.*` root (with `DefaultDraftService` in
`.internal`, `@Service("tmDraftService")` preserved) AND
`DraftAlreadyAppliedException` relocated from `tournament.internal.*`
to the existing `tournament.exceptions.*` named-interface sub-package,
**so that** E22's `de.vvwt.tm.web.DraftController` migration per DEC-40
Clause D can consume the interface (whose method signatures reference
the now-public `tournament.draft.*` VOs from E33S04) + catch the
exception via `tournament::exceptions` without reaching into
`tournament.internal.*`.

---

## Context

`DraftService` is the most signature-coupled of the 4 services:
its public methods reference `DraftConfig`, `DraftPreviewResult`, etc.
as parameter and return types. These VOs were relocated from
`tournament.internal.draft.*` to `tournament.draft.*` in E33S04
(prerequisite). The interface extraction in E33S05 then declares
signatures referencing the now-public VOs without violating DEC-35.

Additionally, `DraftAlreadyAppliedException` (currently in
`tournament.internal`) is consumed by `DraftController.java:3` —
post-E22 controller migration would create a `web → tournament.internal`
boundary violation. Relocate to `tournament.exceptions` (existing
named interface) in this story atomically with the interface extraction.

Classification: Q-1b pure refactor.
