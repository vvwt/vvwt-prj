# Story E33S06: Promote `MatchGenerator` interface from `tournament.internal.*` to `tournament.*` root

## User Story

**As a** maintainer of the `de.vvwt.tm.tournament` Modulith module post-E21,
**I want** the `MatchGenerator` strategy interface (currently in
`de.vvwt.tm.tournament.internal.MatchGenerator`) promoted to the
public `de.vvwt.tm.tournament.*` root package (file move, no
declaration change since it is already an interface),
**so that** `MatchGeneratorRegistry` (already public, exposes
`Map<String, MatchGenerator>` and accepts `List<MatchGenerator>` in
its constructor) no longer leaks an `.internal` type across module
boundaries — closing a latent DEC-35 violation that any future
cross-module consumer of the Registry would expose at compile time.

---

## Context

`MatchGeneratorRegistry` is at `de.vvwt.tm.tournament.MatchGeneratorRegistry`
(public root, E21S08 reconstruction-in-place). Its public API exposes
`MatchGenerator` (current FQN: `tournament.internal.MatchGenerator`)
in two places:
- Constructor parameter: `public MatchGeneratorRegistry(List<MatchGenerator> generators)`
- Field: `private final Map<String, MatchGenerator> generatorsByBeanId`
  (used by public method `get(String beanId): MatchGenerator`)

Per DEC-35 § Public package required content: types that cross module
boundaries (parameter / return types of public APIs) must themselves
live in public packages. `MatchGenerator` violating this rule is the
direct counterpart to E31S01's repository-interface extraction — same
class of latent debt.

`MatchGenerator` is ALREADY an interface (Strategy pattern), so this is
a simpler promote-to-root than the service extractions in E33S01-S05
(no `Default*` rename, no class→interface conversion). Just file move
+ FQN-import updates in 3 sites.

`RoundRobinMatchGenerator` (the concrete strategy impl) STAYS in
`tournament.internal` and continues to `implements MatchGenerator`
(import line updates from `tournament.internal.MatchGenerator` →
`tournament.MatchGenerator`).

Classification: Q-1b pure refactor. Smallest E33 story.
