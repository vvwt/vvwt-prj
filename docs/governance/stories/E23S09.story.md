# Story E23S09: Q-1b relocate `CertificateTemplateController` + 2 Response DTOs (`CertificateTemplateMetadataResponse`, `CertificateTemplateVariableResponse`) to `de.vvwt.tm.web.certificate.*` (URLs preserved at legacy paths until Cutover-2)

## User Story

**As a** maintainer of the `de.vvwt.tm.web` Modulith module,
**I want** `CertificateTemplateController` + its 2 Response DTOs relocated
from `de.vvwt.tm.infrastructure.web.certificate.*` to `de.vvwt.tm.web.certificate.*`
with `@ApplicationModuleTest(web, RANDOM_PORT)` test annotation + per-endpoint
DEC-40 Clause B DTO-vs-entity justification + per-method DEC-40 Clause A
Trigger-β check,
**so that** the certificate controller sits in the DEC-40 Primary-Adapter-Isolation
web module per Clause D, URL-renames can land atomically at E23S10 Cutover-2,
and DEC-40 Trigger α/β governance checks are recorded per Brief v4 C-10.

---

## Context

Per Brief v4 D-6, web.allowedDependencies post-this-story INCLUDES certificate:
web grows from `{tenant, tournament, tournament::exceptions, scoring, photo}`
(post-E23S05 Cutover-1) to `{tenant, tournament, tournament::exceptions,
scoring, certificate, photo}`. Brief v4 O-10 documents this is the LAST
epic before DEC-40 Trigger α fires (post-E23 count excl. tenant = 4;
E24 +print = 5 → Trigger α fires at E24).

Q-1b whole-class relocation per DEC-40 Clause D + DEC-22 §refactor-clause.
URL preservation is essential for E23S10 atomic Cutover-2 (URL rename
happens atomically there, not here).

Per Brief v4 C-10, two per-controller-method governance checks are MANDATORY
AC in this story: (1) Clause B DTO-vs-entity disposition per endpoint with
explicit B(a/b/c/d) citation, (2) Clause A Trigger-β examination per method.

## Acceptance Criteria

- [ ] **AC-RELOCATION**: `CertificateTemplateController` moves whole-class
  from `de.vvwt.tm.infrastructure.web.certificate.CertificateTemplateController`
  to `de.vvwt.tm.web.certificate.CertificateTemplateController`.
  `CertificateTemplateMetadataResponse` + `CertificateTemplateVariableResponse`
  DTOs move to `de.vvwt.tm.web.certificate.*`.
- [ ] **AC-URL-UNCHANGED**: All 4 `@*Mapping` path attributes preserved
  verbatim during parallel phase:
  (1) `POST /api/tournaments/{tournamentId}/certificate-template` (upload)
  (2) `GET /api/tournaments/{tournamentId}/certificate-template` (retrieve file)
  (3) `GET /api/tournaments/{tournamentId}/certificate-template/info` (metadata)
  (4) `DELETE /api/tournaments/{tournamentId}/certificate-template` (delete)
  (5) `GET /api/certificate-template/variables` (variable catalog)
  URL renames DEFERRED to E23S10 Cutover-2.
- [ ] **AC-ALLOWED-DEPS-EXPANDED**: `de.vvwt.tm.web/package-info.java`
  `@ApplicationModule(allowedDependencies = {...})` expanded to include
  `"certificate"`. Post-story count excluding tenant = 4
  (tournament, scoring, photo, certificate). Still below Trigger α (≥5).
- [ ] **AC-TRIGGER-BETA-CHECK**: DEC-40 Clause A Trigger β examined per
  method of CertificateTemplateController. Story AC documents findings:
  each method's cross-bounded-context imports enumerated. If any method
  imports from >2 bounded contexts, the story AC escalates (L2.5 Clause C
  evaluation required). Expected result: no method imports from >2 contexts
  (certificate + web-internal DTOs at most; tenant is not a bounded context
  for Trigger β purposes per DEC-40 "excluding tenant").
- [ ] **AC-DTO-DISPOSITION-CLAUSE-B-PER-ENDPOINT**: DEC-40 Clause B
  per-endpoint decision documented:
  - Upload endpoint: request body is `MultipartFile`, no DTO. Response:
    empty 200 OK — no DTO. Clause B non-applicable.
  - Retrieve-file endpoint: response is file `byte[]` stream, no JSON DTO.
    Clause B non-applicable.
  - Info endpoint: response is `CertificateTemplateMetadataResponse` DTO —
    preserved as web-internal DTO on Clause B(a) field-omission grounds
    (entity `CertificateTemplateMetadata` may contain internal fields like
    `tenantId` or storage-location path not exposed in JSON).
  - Delete endpoint: response 204 No Content — no DTO. Clause B non-applicable.
  - Variables endpoint: response is `List<CertificateTemplateVariableResponse>`
    — preserved as web-internal DTO on Clause B(d) field-aliasing grounds
    (if JSON shape differs from domain `CertificateTemplateVariable` enum
    shape) or B(b) contract-stability.
  - All 5 dispositions documented in story AC or controller Javadoc.
- [ ] **AC-TEST-RELOCATION-IT**: `CertificateTemplateControllerIT` test
  class relocates to `de.vvwt.tm.web.certificate.CertificateTemplateControllerIT`.
  Annotation changed from legacy `@SpringBootTest(RANDOM_PORT)` (pre-DEC-38)
  OR `@ApplicationModuleTest(tournament)` (if already changed by E31S01)
  to `@ApplicationModuleTest(webEnvironment = WebEnvironment.RANDOM_PORT)`
  targeting the `web` module per DEC-38 Clause A + DEC-40 2026-04-22
  Amendment. Existing assertions remain GREEN.
- [ ] **AC-TEST-SLICE-UNCHANGED**: If `CertificateTemplateControllerSliceTest`
  exists (`@WebMvcTest`), it retains `@WebMvcTest` per DEC-38 Clause C

- [ ] **AC-MOCKITOBEAN-REVERSE-CASE**: Per DEC-38 2026-04-22 Amendment

  existing IT is REMOVED (real bean now in web's allowedDeps via certificate

- [ ] **AC-TESTING-DEC36**: All relocated tests in different package than

- [ ] **AC-TESTING-QB-REGRESSION-GATE**: Per DEC-22 §refactor-clause Q-1b,
