# Story E24S02: Q-1a TDD RED-first fresh reconstruction of `LaufzettelAssembler` — new public interface at `de.vvwt.tm.print.*` + `DefaultLaufzettelAssembler` impl at `.internal.*` + `LaufzettelRow` VO + fresh deep-behaviour tests

## User Story

**As a** maintainer of `vvwt-tm-web` reconstructing the print bounded context
under strict DEC-22 Iron Law,
**I want** a fresh `LaufzettelAssembler` public interface + `DefaultLaufzettelAssembler`
implementation + `LaufzettelRow` VO authored TDD RED-first at the new
`de.vvwt.tm.print.*` module, with behaviour covering the scenario set of
team-schedule assembly (phases, breaks, activities, timeline, avatars) —
with legacy `infrastructure.print.LaufzettelAssembler` UNTOUCHED,
**so that** the print module has its first reconstructed assembler meeting
DEC-22 Iron Law (every line of production code preceded by a failing test);
legacy continues to serve legacy PrintController until atomic cutover (S07).
