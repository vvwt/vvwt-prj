# Story: Extract interfaces for DEC-58/DEC-72 violations in `vvwt-slotopt-dispatcher`

## User Story

**As a** developer and maintainer of the `vvwt-slotopt-dispatcher` Maven module,
**I want** every self-created Spring component in the module addressable through a public interface,
**so that** AOP proxies are JDK-proxy-clean, tests mock interfaces without workarounds, and the module complies with the DEC-58 interface mandate as amended by DEC-72.

---

## Context

DEC-58 (amended by DEC-72) mandates that every self-created Spring component be addressable through a public interface. `vvwt-slotopt-dispatcher` was **never audited** for DEC-58 compliance — E51S19's "codebase-wide audit" AC was scoped to `vvwt-tm-web`'s `.internal` packages only. This story is the first DEC-58 remediation pass over the module; the module uses the public-package / `.internal`-package convention (it is **not** a Spring Modulith module — DEC-21 Modulith applies to `vvwt-tm-web` only).

A 2026-05-15 codebase audit found DEC-58 violations in `vvwt-slotopt-dispatcher`, but that audit was a **stereotype-only scan** — it did not enumerate `@Bean`-factory-produced first-party service beans, which DEC-72 Clause A-ext now brings into the mandate's scope. The complete in-scope violation set is therefore **re-derived fresh by Delivery at the delivery HEAD** (AC-GOV-FRESH-AUDIT); the 2026-05-15 audit is the non-authoritative starting point only.

This story is a **predominantly mechanical refactor**: extract an interface, move/rename the implementation, re-type consumers. It changes no production logic — but interface extraction shifts Spring AOP proxying from CGLIB to JDK dynamic proxies for advised beans, which AC-TEST-AOP-PROXY-SHIFT covers explicitly.

---

## Acceptance Criteria

### Testing

- [ ] **AC-TEST-SUITE-GREEN** — the module's full existing test suite remains GREEN: `mvn verify` is BUILD SUCCESS for `vvwt-slotopt-dispatcher` (DEC-54). Interface extraction changes no production logic; the existing suite is the regression gate.
- [ ] **AC-TEST-REFACTOR-CLASSIFICATION** — for each remediated target Delivery classifies the change: pure interface extraction with the implementation body unchanged AND a trustworthy TDD-authored existing test oracle is a mechanical (Q-1b) refactor — no RED-first test (DEC-58 § Implementation; DEC-22 § "refactor as needed"; DEC-36 § Impact precedent); a target lacking a trustworthy TDD-authored test oracle is routed to Q-1a fresh RED-first against the new interface contract before extraction. The impl-report records the per-target classification.
- [ ] **AC-TEST-AOP-PROXY-SHIFT** — interface extraction shifts Spring AOP proxying from a CGLIB subclass proxy to a JDK interface proxy for any advised bean. For each remediated target advised by Spring AOP (`@Scheduled` / `@Transactional` / `@Async` / etc.), Delivery verifies the **specific** proxied behaviour still holds after extraction — e.g. a `@Scheduled` method still fires on schedule. Verification is an existing test that exercises that proxied behaviour staying green, or — where none exists — a fresh Q-1a RED-first test asserting the concrete proxied behaviour (a property with a genuine failing state, not a vacuous "no change" assertion). The impl-report lists the advised targets and the per-target evidence.
- [ ] **AC-TEST-CROSS-PACKAGE-INTERFACE** — every test class in a Java package different from a remediated target type-references and mocks the **public interface**, not the `Default{Foo}` implementation class (DEC-36); `@MockitoBean(name=...)` references to renamed beans are updated.

### Governance

- [ ] **AC-GOV-FRESH-AUDIT** — Delivery re-derives the full `vvwt-slotopt-dispatcher` DEC-58/DEC-72 violation list at the delivery HEAD: every `@Service` / `@Component` / hand-authored concrete `@Repository` class **and** every first-party service-shaped bean produced by a `@Bean` factory method (DEC-72 Clause A-ext), **minus** the exclusion set — DEC-58 Clause C (Spring Data repository interfaces), DEC-58 Clause D (`@RestController` / `@Controller` / `@Configuration`), and DEC-72 Clause D-ext (`@ConfigurationProperties` holders **including the composite `@Component`+`@ConfigurationProperties` case**; `@ControllerAdvice` / `@RestControllerAdvice`; framework-config-only adapter beans). The exclusion set applies to the **produced bean's shape** for `@Bean` methods; a `@Bean` method returning a third-party framework type produces no first-party bean and is out of scope. A bean already implementing a first-party public interface is **already-compliant**, not a violation. The qa-report enumerates the final list with a per-class verdict (remediated / excluded-with-clause / already-compliant).
- [ ] **AC-GOV-INTERFACE-EXTRACTION** — every behavior-bearing violator gets a `{Foo}` interface in the public package of its owning context and a `Default{Foo}` implementation in the corresponding `.internal` package, per the DEC-35 / DEC-58 naming canon (`I`-prefix forbidden; a noun-named class such as `JcsCanonicalizer` lifts its own name as the interface name). A violator currently residing in a public package as a concrete class is replaced by its `{Foo}` interface in that package, the concrete class moving into `.internal` as `Default{Foo}`.
- [ ] **AC-GOV-REPOSITORY-OPTION-B** — any hand-authored concrete `@Repository` violator found at HEAD is remediated via DEC-58 Clause C **option (b)** — a hand-authored interface over the existing implementation, implementation body unchanged. Option (a) (Spring Data upgrade) is out of scope.
- [ ] **AC-GOV-EXCLUSIONS-NOT-EXTRACTED** — `@ConfigurationProperties` holders, `@ControllerAdvice` / `@RestControllerAdvice` beans, and framework-config-only adapter beans found at HEAD are NOT interface-extracted (DEC-72 Clause D-ext); the qa-report lists each excluded bean against its governing clause.
- [ ] **AC-GOV-CONSUMER-REWIRING** — production-side cross-package injection sites of each remediated target switch to the interface type, in the **same commit** as the extraction; `@Qualifier` and explicit bean-name wiring is audited and updated; no autowiring ambiguity or break is introduced.
- [ ] **AC-GOV-NO-BEHAVIOUR-CHANGE** — no production logic changes: the diff shows interface extraction, class rename to `Default{Foo}`, package move, and consumer re-typing only — no change inside any implementation method body.
- [ ] **AC-GOV-BUILD-HYGIENE** — `mvn verify` exits zero (DEC-54); all Java touches compile warning-free (DEC-29) and pass Spotless / google-java-format (DEC-30); no test-only production member is introduced (DEC-70).
- [ ] **AC-GOV-COMMIT-FORMAT** — commit subjects use `chore(E57S03):` (RED tests, refactor, housekeeping) and `feat(E57S03):` (any GREEN production change) prefixes per the close-story.sh contract.
