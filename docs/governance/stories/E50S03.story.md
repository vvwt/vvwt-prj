# Story: Display SPA Header reposition — Logo + Connection-Indicator into Sidebar-Top at field-header band height

## User Story

**As a** tournament operator using the public Display screen at venue,
**I want** the brand logo and WebSocket connection indicator to occupy only the area above the right-column group standings (at the same height as the field-header band),
**so that** the previously wasted top white band is freed for tournament data and the screen real estate is used efficiently.

---

## Context

Predecessor: E50S02 (PR #227 merged 2026-05-09) implemented a single-band header at field-header band height per its 18 ACs, but the Brief-AC-envelope did not capture the user's actual visual target. The current rendering still has a full-width white top band (`App.svelte:356-359 <header class="display-header">` at `height: 2.8em`) above the dark-blue field-headers band — wasted vertical space.

User clarification 2026-05-10: the Logo + ConnectionStatusIndicator must live INSIDE the right Sidebar (`div.overview-layout__sidebar`), at the TOP, with the same band height as `court-grid__headers` (the `Feld 1`/`Feld 2`/`Feld 3` row). They must be a SEPARATE component from the court-grid (clean DOM separation), but visually aligned via equal band height — producing a single visual line across the screen on field-header height.

This story supersedes E50S02's AC envelope per user-intent clarification 2026-05-10; the new layout cleanly separates Sidebar-branding from court-grid data while reclaiming vertical space.
