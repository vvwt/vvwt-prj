# Story E37S07: job package — JobController + JobService + JobRepository + JobRecord + RawPhaseDef de/serializers + SubmitJobRequest/Response (Q-1a TDD RED-first against spec)

## User Story

**As a** Tournament Manager submitting an optimization job to the dispatcher,
**I want** to POST a job containing a JobDef + RawPhaseDef payload and receive a jobId for later result retrieval,
**so that** the dispatcher can decompose the job into packets for distributed compute and the structural-fingerprint cache (DEC-9) can amortize repeated tournament structures across organizers.

---

## Context

The job package owns: JobController (HTTP `POST /api/submit-job`), JobService (interface + DefaultJobService impl), JobRepository (Spring Data JDBC), JobRecord entity, RawPhaseDef de/serializers (custom Jackson serializers — types live in vvwt-slotopt-worker-lib per DEC-11), SubmitJobRequest/Response DTOs.

Per DEC-9: TeamAvatars are represented exclusively by structural triple (phaseId, groupNumber, groupPosition); no UUID crosses the optimizer boundary. RawPhaseDef wire payload constraint enforced at this story.

This story is authored against E37S02 spec sections (a) shared concerns, (b) dispatcher contract submit-job endpoint. No legacy inspection.

### Story-specific ACs

- [ ] **AC-JOB-RECORD-ENTITY**: `de.vvwt.slotopt.dispatcher.job.JobRecord` Spring Data JDBC POJO with fields per spec section (b): `Long id`, `UUID jobId` (UNIQUE), `Instant submittedAt`, `String jobDefJson` (canonicalized), `String status` (e.g., `RECEIVED`, `DECOMPOSED`, `COMPLETED`).
- [ ] **AC-JOB-REPOSITORY**: `de.vvwt.slotopt.dispatcher.job.JobRepository extends CrudRepository<JobRecord, Long>`. Custom finder: `Optional<JobRecord> findByJobId(UUID jobId)`.
- [ ] **AC-JOB-SERVICE**: `de.vvwt.slotopt.dispatcher.job.JobService` interface + `de.vvwt.slotopt.dispatcher.job.internal.DefaultJobService` impl. Method `SubmitJobResponse submitJob(SubmitJobRequest request)`. Behavior: (1) validate RawPhaseDef payload conforms to DEC-9 (no UUIDs in payload); (2) compute structural fingerprint via worker-lib's `StructuralFingerprint` type; (3) generate jobId UUID; (4) persist JobRecord; (5) return SubmitJobResponse. RED-first authored.
- [ ] **AC-JOB-CONTROLLER**: `de.vvwt.slotopt.dispatcher.job.JobController` `@PostMapping("/api/submit-job")`. Accepts JSON `SubmitJobRequest`. Returns JSON `SubmitJobResponse` HTTP 201. Validation errors → 400.
- [ ] **AC-SUBMIT-JOB-DTOs**: `SubmitJobRequest(JobDef jobDef, RawPhaseDef phase)` (records). `SubmitJobResponse(UUID jobId, Instant submittedAt)`. Field names match spec verbatim.
- [ ] **AC-RAW-PHASE-DEF-SERIALIZER**: `de.vvwt.slotopt.dispatcher.job.RawPhaseDefSerializer` (Jackson `JsonSerializer<RawPhaseDef>`) and `RawPhaseDefDeserializer`. Wire format = `{phaseId, rows: [[{group, pos}, ...]]}` per DEC-9 + spec (b). Tests cover: roundtrip serialization preserving value; deserialization of valid JSON; rejection of payloads containing UUID fields (DEC-9 violation → throw IOException).
- [ ] **AC-DEC9-COMPLIANCE**: Submitting a SubmitJobRequest with UUID-bearing fields in RawPhaseDef → HTTP 400 with explicit "DEC-9 violation: TeamAvatar UUIDs not permitted in optimizer payload" error message. Test covers this.
- [ ] **AC-DEC26-COMPLIANT-DAO-IT**: `JobRepositoryIT` follows DEC-26 three-rule pattern.
- [ ] **AC-MOCKMVC-CONTROLLER-TEST**: `JobControllerSliceTest` (`@WebMvcTest`) mocks JobService interface; verifies HTTP layer behavior.

## Notes

- **DEC-9 enforcement at the boundary**: This is the story where DEC-9's "UUIDs do not cross the optimizer boundary" gets enforced in code. The RawPhaseDef de/serializer is the gate.
- **StructuralFingerprint computation**: delegated to worker-lib's `StructuralFingerprint` type (E35-rebuilt; trustworthy).
- **Role-based authorization**: spec may require submitJob caller to have `INFO_UPLOADER` role (per DEC-6 role schema in identity package). If so, JobService delegates to KeyRegistrationService for role lookup (signed-request authentication is a future concern; V1 may use a simpler caller-asserts-role pattern per E01 design).
