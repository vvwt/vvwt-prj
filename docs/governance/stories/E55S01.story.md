# Story E55S01: Foundation — new `phaselifecycle` Modulith module + interface contracts + DEC-58 audit

## User Story

**As a** Tournament Manager developer (Delivery Agent),
**I want** a clean new Spring Modulith module `de.vvwt.tm.phaselifecycle` with all 5 public interface contracts declared (PhaseLifecycleOrchestrator, PhaseLifecycleJobRepository, WorkerRegistry, JobDrainService, CancelFlagRegistry) before any business logic or schema or migration lands,
**so that** subsequent E55 stories (E55S02 schema + DAO; E55S03 worker registry impl; E55S04 orchestrator drain logic; E55S05 cancel mechanism; E55S06 migration) can implement against stable interface contracts in the module-root package, and so that `ApplicationModules.verify()` remains green from the very first commit of this Epic, and so that DEC-58 universal-interface-mandate compliance is established up-front rather than retrofitted.

---

## Context

DEC-64 (authored 2026-05-11) introduces a new Spring Modulith module `de.vvwt.tm.phaselifecycle` as the Saga-Orchestrator mediator that replaces DEC-55 D-3's events-only pipeline. Per DEC-64 D-2 and DEC-21:

```java
// vvwt-tm-web/src/main/java/de/vvwt/tm/phaselifecycle/package-info.java
@org.springframework.modulith.ApplicationModule(
    allowedDependencies = {"tournament", "slotopt", "tenant"})
package de.vvwt.tm.phaselifecycle;
```

The module hosts the orchestrator and its dependencies. Per DEC-64 D-14 + DEC-58, every self-created Spring component MUST have a public interface in the module-root package + `Default*` implementation in the `.internal` sub-package. The 5 beans to be declared in this Story are:

| Public Interface (module-root) | Default Implementation (.internal) | Role |
|---|---|---|
| `PhaseLifecycleOrchestrator` | `DefaultPhaseLifecycleOrchestrator` | Drains jobs; calls MatchGen → L1 → L2 → SlotOpt → write-back |
| `PhaseLifecycleJobRepository` | `DefaultPhaseLifecycleJobRepository` | DAO for `phase_lifecycle_job` table (rows, CAS claim) |
| `WorkerRegistry` | `DefaultWorkerRegistry` | `ConcurrentHashMap<UUID, ExecutorService>` per-tournament workers |
| `JobDrainService` | `DefaultJobDrainService` | Tick logic: claim next pending row + dispatch to orchestrator |
| `CancelFlagRegistry` | `DefaultCancelFlagRegistry` | In-memory mirror of DB `cancelled` flag observed by L3 permutation loop |

This Story declares the interfaces ONLY — methods may be stubbed with `throw new UnsupportedOperationException("E55S04")` placeholders pointing to the implementing Story. Implementation methods are written in subsequent Stories.

E55S02-S07 ALL depend on the interfaces declared here. This is the foundation.

DEC-58 hard-AC codebase-wide audit closure-criterion follows the E53S04 precedent: Delivery's qa-report MUST enumerate every self-created Spring component in the new module and classify each as (a) interface-declared + Default-impl-placeholder, (b) verified out-of-scope (e.g., DTO records), or (c) deferred to a later E55 Story with explicit reference.
