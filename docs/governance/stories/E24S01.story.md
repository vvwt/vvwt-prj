## User Story

**As a** maintainer of `vvwt-tm-web` beginning E24 print-context reconstruction
under strict DEC-22 Iron Law,
**I want** a new `de.vvwt.tm.print` Modulith module declared with
`allowedDependencies = {"tournament"}`, a new public class
`de.vvwt.tm.tournament.exceptions.TournamentNotFoundException` carrying
`@ResponseStatus(HttpStatus.NOT_FOUND)` for defense-in-depth, and 2 legacy
Snapshot-Driven assembler unit tests deleted per DEC-41 §3 — with legacy
production code at `infrastructure.print.*` UNTOUCHED,
**so that** subsequent stories can Q-1a TDD-reconstruct print-domain classes
fresh at the new module without prior Q-1b relocation, DEC-40 Trigger-α
verdict is recorded (Brief v6 T-1: L2 stays), and strict DEC-22 Iron Law
applies throughout E24.

### New public TournamentNotFoundException (Brief D-6 + R-3)

- [ ] **AC-EXCEPTION-CREATE-PUBLIC-WITH-RESPONSESTATUS**: New file at
  `vvwt-tm-web/src/main/java/de/vvwt/tm/tournament/exceptions/TournamentNotFoundException.java`.
  **Behavioral contract** (NOT an implementation specification — the
  implementer drives shape from the RED-first test below):
  - **Visibility**: `public class` (NOT package-private — public surface
    of the `tournament::exceptions` named-interface sub-package).
  - **Inheritance**: extends `RuntimeException` (matches legacy semantic;
    unchecked exception).
  - **Annotation**: must carry `@ResponseStatus(HttpStatus.NOT_FOUND)`
    from `org.springframework.web.bind.annotation` package (Brief R-3
    defense-in-depth — Spring's `ResponseStatusExceptionResolver`
    maps the exception to HTTP 404 when no `@ExceptionHandler` matches).
  - **Constructor signature**: single-argument `(java.util.UUID tournamentId)`.
  - **Message contract**: the string returned by `getMessage()` MUST
    contain the `tournamentId.toString()` value (the test asserts
    `getMessage().contains(tournamentId.toString())` — implementer
    chooses message format that satisfies it; the legacy precedent is
    `"Tournament not found: <UUID>"` but is not prescribed).
  - **Behavior**: thrown when a tournament lookup yields no row in the
    active tenant scope.
  All shape decisions beyond the above are the implementer's call,
  driven RED-first by AC-EXCEPTION-REDFIRST-TEST.
- [ ] **AC-EXCEPTION-REDFIRST-TEST**: New RED-first unit test
  `TournamentNotFoundExceptionTest` at `de.vvwt.tm.tournament.exceptions.*`
  asserting (a) extends RuntimeException; (b) message format includes
  UUID; (c) class has `@ResponseStatus(HttpStatus.NOT_FOUND)` annotation
  (reflection). RED initial (class absent); GREEN after class creation.
  Per DEC-22 Iron Law for new class.
- [ ] **AC-LEGACY-EXCEPTION-UNTOUCHED**: Legacy
  `de.vvwt.tm.infrastructure.print.TournamentNotFoundException`
  (package-private, with `@ResponseStatus`) REMAINS untouched at S01.
  Legacy `PrintController`'s **9** throw-sites (empirically verified
  2026-04-23 via `grep -c "new TournamentNotFoundException" PrintController.java`:
  lines 231, 289, 302, 379, 480, 491, 849, 896, 976) still reference the
  legacy package-private class (via same-package access). Legacy `PrintControllerAdvice`
  unchanged. Legacy dies with S07 cutover.
- [ ] **AC-DUAL-EXCEPTION-COEXISTENCE**: Post-S01, BOTH exception classes
  exist on disk simultaneously: legacy `infrastructure.print.TournamentNotFoundException`
  (package-private, served by legacy PrintController) + new public
  `tournament.exceptions.TournamentNotFoundException` (not yet thrown by
  any caller — S05/S06 fresh controllers will throw it). No collision
  (different FQNs, different visibility).
