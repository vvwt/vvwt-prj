# Story E33S01: Extract `TournamentService` public interface + `DefaultTournamentService` impl (DEC-35 retrofit pioneer)

## User Story

**As a** maintainer of the `de.vvwt.tm.tournament` Modulith module post-E21,
**I want** `TournamentService` exposed as a public interface in
`de.vvwt.tm.tournament.*` root with a `DefaultTournamentService`
implementation in `de.vvwt.tm.tournament.internal.*` (preserving the
`@Service("tmTournamentService")` bean qualifier for unchanged
`@Qualifier`-consumer wiring),
**so that** E22's `de.vvwt.tm.web.TournamentController` migration per
DEC-40 Clause D can consume the interface across module boundaries
without reaching into `tournament.internal.*` (forbidden by Spring
Modulith), and so that this story establishes the reusable extraction
pattern for E33S02 / E33S03 / E33S05.

---

## Context

E21 delivered `TournamentService` as a concrete `@Service` class in
`de.vvwt.tm.tournament.internal.TournamentService`. This was
undetected-DEC-35-deviation while `TournamentController` lived in the
same module (same-package white-box access is permitted by DEC-36).
DEC-40 Primary-Adapter-Isolation (2026-04-22, committed `478f43a`)
forces resolution: E22 relocates `TournamentController` to
`de.vvwt.tm.web.*`, at which point `web → tournament.internal.*` is
forbidden by Spring Modulith boundary rules.

E33S01 is the pioneer story of the E33 DEC-35 retrofit. It establishes
the extraction pattern that E33S02/S03/S05 follow.

Classification: Q-1b pure refactor per DEC-22 § refactor-clause +
E31S01 precedent. No RED-first test required. All existing
`TournamentServiceTest` + `TournamentControllerIT` + `TournamentControllerSliceTest`
assertions remain GREEN as regression gate.
