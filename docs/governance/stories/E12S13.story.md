# Story: Close the residual web/print 1:1 layout divergence on the certificate template — convert the remaining absolute-px declarations on screen-media layout-affecting selectors of `_certificate_styles.mustache` to mathematically-equivalent `cqw` units (extending E12S12's Path A pattern from spacing to fonts/cosmetics), AND align the `@media print` `.page` padding mm values to the proportional mirror of the screen-media `cqw` padding fractions; web vs. print photo-wrap aspect ratio converges to within rendering noise

## User Story

**As a** tournament organizer who renders Urkunden in the browser AND
in the print preview AND on the production jlink-deployed test system,
**I want** the certificate's web view and print view to render the
SAME layout proportions (the photo-wrap aspect ratio is the same,
within rendering noise, in both contexts),
**so that** the operator's "what I see on screen is what gets printed"
expectation is met — extending the E12S12 result (web layout
viewport-invariant) to also match print layout, eliminating the
~7 % residual divergence that E12S12 documented as out-of-scope.

---

## Context

E12S12 (commit `68f7eec6`) shipped Path A — `cqh` → `cqw` conversion on
the spacing-related selectors of `_certificate_styles.mustache` — plus
operator-tuned vertical-spacing values. After E12S12 the web rendering
became viewport-height-invariant (photo-wrap AR constant at ~2.024
across the operator's full viewport range). However, E12S12 explicitly
fenced two surfaces out of scope:

- the absolute-pixel font-size and cosmetic-spacing declarations in
  the screen-media rules (`.lockup-row` 36px, `.urkunde-badge .label`
  28px, `.place-meta .of` 18px, `.place-meta .lbl` 13px, `.footer`
  10px, `.hero-subtitle` 14px, `.wm-tag` 9px and others — full
  inventory in § Root Cause Analysis);
- the `@media print` `.page` `padding` values (E12S11's `12mm 18mm
  10mm`), explicitly fine-tunable per E12S11's RCA but never aligned
  to the screen-media cqw padding fractions.

Discovery 2026-06-06 examined the residual `web AR ≈ 2.024` vs
`print AR ≈ 2.176` (the ~7 % gap E12S12 documented) and verified
algebraically that the dominant contributor is **the `@media print`
mm padding values diverging from the screen-media cqw padding
proportions**, not the absolute-pixel font sizes. Both contribute,
but the font-only conversion alone would barely move print AR
(~2.176 → ~2.178); converting `@media print` padding to the
proportional-mirror mm values (`10.504 mm 20.79 mm 8.405 mm` = the
exact `3.537 % / 7 % / 2.830 %` shares of A4-landscape 297 mm) closes
the bulk of the gap to within ~2.6 % (within rendering noise).

The bug surface is the same Mustache template:
`vvwt-prj/vvwt-tm-web/src/main/resources/templates/certificate/_certificate_styles.mustache`.
This story is `track: bug-triage` per the Discovery Bug-Triage Flow in
`.gaai/core/agents/discovery.agent.md`. It depends on E12S12
(the screen-media rules this story now extends to a full cqw
conversion already lost their `cqh` literals in E12S12).

## Root Cause Analysis

Empirically established in Discovery via algebraic analysis of the
post-E12S12 staging template (commit `68f7eec6`) augmented by
container-width × cqw-fraction × inner-AR arithmetic.

### Verified root causes (Path A extension targets)

**(1) Absolute-pixel font and cosmetic-spacing declarations remain
on layout-affecting properties in screen-media rules.** After
E12S12's `cqh → cqw` spacing pass, the file still carries the
following absolute-pixel literals on properties that contribute to
the flex-stacked vertical sum above and below `.photo-wrap` (and
therefore to its leftover height, and therefore to its AR):

| Selector | Property | Pre-E12S13 value | Web px (at `.stage = 1180px`) | Print px (at `.page = 297 mm = 1122.5 px`) | Relative print shrinkage |
|---|---|---|---|---|---|
| `.lockup-row` | `font-size` | `36px` | 36 | 36 | 0 % (px is medium-invariant) |
| `.lockup-row .hex` | `width` / `height` | `36px` / `36px` | 36 / 36 | 36 / 36 | 0 % |
| `.wm-tag` | `font-size` / `margin-top` | `9px` / `6px` | 9 / 6 | 9 / 6 | 0 % |
| `.meta` | `gap` | `36px` | 36 | 36 | 0 % |
| `.urkunde-badge` | `padding` | `14px 28px` | 14 / 28 | 14 / 28 | 0 % |
| `.urkunde-badge .label` | `font-size` | `28px` | 28 | 28 | 0 % |
| `.hero-title` | `margin` (top, `8px 0 0`) | `8px` | 8 | 8 | 0 % |
| `.hero-subtitle` | `font-size` / `margin-top` | `14px` / `10px` | 14 / 10 | 14 / 10 | 0 % |
| `.placement` | `gap` | `28px` | 28 | 28 | 0 % |
| `.place-meta` | `padding-bottom` | `6px` | 6 | 6 | 0 % |
| `.place-meta .row` | `gap` | `18px` | 18 | 18 | 0 % |
| `.place-meta .lbl` | `font-size` | `13px` | 13 | 13 | 0 % |
| `.place-meta .of` | `font-size` | `18px` | 18 | 18 | 0 % |
| `.place-meta .accent` | `width` / `margin-bottom` | `56px` / `12px` | 56 / 12 | 56 / 12 | 0 % |
| `.stamp` | `width` / `height` / `right` / `bottom` | `88px` / `88px` / `16px` / `16px` | 88 / 88 / 16 / 16 | 88 / 88 / 16 / 16 | 0 % |
| `.footer` | `font-size` | `10px` | 10 | 10 | 0 % |

Because absolute-pixel sizes are medium-invariant but the
container-width changes (web `.stage = 1180 px`, print `.page =
1123.2 px`), each absolute-pixel value takes a slightly **different
proportion** of the container in each medium. The aggregate effect
on the flex-leftover photo-wrap height is small (~5 px on print),
which is why this is NOT the dominant driver.

**(2) `@media print` `.page` `padding` mm values diverge from the
screen-media cqw padding fractions.** The screen-media rule (post
E12S12) declares `.page { padding: 3.537cqw 7cqw 2.830cqw }`. The
`@media print` rule from E12S11 forces `.page { padding: 12mm 18mm
10mm }`. The proportional mirror at A4-landscape (297 mm × 210 mm)
would be:

| Edge | Screen-media (cqw fraction of `.page` width) | Proportional mirror at print (mm fraction of 297 mm) | Current print mm (E12S11) | Δ |
|---|---|---|---|---|
| top | `3.537 cqw` = 3.537 % | `10.504 mm` (3.537 % × 297) | `12 mm` | +1.50 mm |
| sides | `7 cqw` = 7.000 % | `20.79 mm` (7.000 % × 297) | `18 mm` | −2.79 mm |
| bottom | `2.830 cqw` = 2.830 % | `8.405 mm` (2.830 % × 297) | `10 mm` | +1.59 mm |

E12S11's RCA explicitly cites these proportional mirror values
("`5 % × 210 = 10.5 mm`, `7 % × 297 = 20.8 mm`, `4 % × 210 = 8.4 mm`")
and explicitly authorizes Delivery to "fine-tune the exact
millimetre values per AC1's visual attestation while keeping the
fixed-mm structural contract." E12S11 Delivery shipped the
slightly-different `12 / 18 / 10 mm` for unrelated visual taste
reasons — this story brings them back into the proportional-mirror
form (using post-E12S12 cqw fractions, not E12S11's pre-conversion
cqh fractions).

### Empirical AR convergence (algebraic simulation)

| Scenario | Web photo-wrap AR | Print photo-wrap AR | Gap |
|---|---|---|---|
| Pre-E12S13 (post-E12S12 baseline at commit `68f7eec6`) | 2.024 | 2.176 | 7.5 % |
| Path A extended to fonts/cosmetics only (no print-padding change) | 2.024 | ~2.178 | 7.6 % (no improvement) |
| Print-padding proportional-mirror only (no font conversion) | 2.024 | ~2.080 | 2.8 % |
| **Both: fonts/cosmetics → cqw AND print-padding → proportional mm (E12S13 target)** | **2.024** | **~2.077** | **~2.6 %** |

The combined fix is the minimum scope that meets the user-stated
"1:1 web/print" goal within rendering noise. The residual ~2.6 %
comes from (a) the screen-media rule's mixed cqw + `clamp()` floor
or ceiling on `.hero-title` / `.place-num` / `.place-meta .team-name`
which are already in the linear `cqw` regime at both 1180 px and
1123 px containers and (b) sub-pixel font-metric differences in
the embedded Plus Jakarta Sans rendering — both below operator
perceptual threshold and explicitly **out of scope** for this story.

### Verified fix (Path A extension)

**Screen-media absolute-px → cqw at the web `.stage = 1180 px` anchor.**
With `.stage { width: min(1180px, 100%) }` and `.page` being the
container, `1 cqw` in the screen media equals `1180 / 100 = 11.80 px`.
The Delivery-target cqw equivalents are:

| Selector | Property | Pre-E12S13 px | Delivery target (cqw, 3 decimals) |
|---|---|---|---|
| `.lockup-row` | `font-size` | `36px` | `3.051cqw` |
| `.lockup-row .hex` | `width` / `height` | `36px` / `36px` | `3.051cqw` / `3.051cqw` |
| `.wm-tag` | `font-size` | `9px` | `0.763cqw` |
| `.wm-tag` | `margin-top` | `6px` | `0.508cqw` |

| `.urkunde-badge` | `padding` (horizontal) | `28px` | `2.373cqw` |
| `.urkunde-badge .label` | `font-size` | `28px` | `2.373cqw` |
| `.hero-title` | `margin-top` | `8px` (in `8px 0 0`) | `0.678cqw` (in `0.678cqw 0 0`) |

At the web `.stage = 1180 px` anchor, these cqw values resolve to
the same px as the pre-E12S13 absolutes — the **web layout is
bit-identical pre- and post-E12S13**. The print rendering shrinks
proportionally because `1 cqw` in print equals `297 mm / 100 ≈
11.225 px` (≈ 4.87 % smaller than web) — closing the residual font
contribution to the AR gap. (The print-px column above uses the
algebraic value `297 mm × 96/25.4 = 1122.52 px`; numeric rounding
is below the AC4 ±2 % tolerance.)

**Print-media padding → proportional mirror of screen-media cqw
padding fractions.** The `@media print` rule's `.page { padding:
12mm 18mm 10mm }` becomes:

| Edge | Pre-E12S13 mm | Delivery target mm (proportional mirror, ±0.05 mm tolerance) |
|---|---|---|
| top | `12mm` | `10.504mm` (= 3.537 % × 297) |
| sides | `18mm` | `20.79mm` (= 7.000 % × 297) |
| bottom | `10mm` | `8.405mm` (= 2.830 % × 297) |

Delivery may round to 2 decimals or 1 decimal (`10.50mm 20.79mm
8.41mm` is acceptable within the ±0.05 mm tolerance). The fixed-mm
structural contract from E12S11 is preserved: print `.page` still
declares `width` AND `height` AND `aspect-ratio: auto` AND `padding`
in fixed-mm (NOT cqw/cqh/cqi/cqb — that constraint from E12S11 AC2
is explicitly maintained).

### Excluded from conversion (preserved as absolute-px / unchanged)

- `1px` borders/dividers (`.divider { height: 1px }`, `.photo-wrap
  { border: 1px solid var(--line) }`) — preserves crisp sub-pixel
  snapping; cqw at sub-1 px values rasterizes inconsistently.
- Letter-spacings (`-1px`, `2.6px`, `3.0px`, `6px`, `.2px`, `.3px`,
  `1.6px`, `.5px`) — typographically intentional micro-kerning;
  cqw values below `0.1 cqw` (= 1.18 px) round to rendering noise.
- `box-shadow` offsets (`0 12px 40px ...`, `0 6px 20px ...`) and
  `filter: blur(6px)` — visual-effect dimensions, no layout
  contribution.
- `body { padding: 24px }` — web-only outer scroll margin around
  `.stage`; the `@media print` rule already overrides this.
- `clamp()` floors and ceilings on `.hero-title`
  (`clamp(40px, 5cqw, 64px)`), `.place-num` (`clamp(64px, 7.5cqw,
  110px)`), `.place-meta .team-name` (`clamp(20px, 2.6cqw, 34px)`) —
  protect readability at extreme container widths; at 1180 px and
  1123.2 px containers all three middle terms are in the linear
  `cqw` regime so the bounds have no effect today.
- The `1pt` / `1mm` / `1px` line-of-truth on `border-radius: 12px`
  (`.photo-wrap`), `border-radius: 4px` (`.page`), `tom-inline .o
  { margin: 0 0.5px }` — cosmetic radii / sub-px kerning, layout-
  invariant.

These exclusions are **explicit** in the diff scope (AC5).
