# Story E36S06: Certificate controller Q-1a TDD rebuild — CertificateTemplateController + 2 DTOs (CertificateTemplateMetadataResponse + CertificateTemplateVariableResponse) (D-7 Option γ at canonical FQN de.vvwt.tm.web.certificate.*)

## User Story

**As a** maintainer of `vvwt-tm-web` continuing Track 2 (Certificate) of Epic E36,
**I want** the legacy certificate-controller Q-1b artefacts at
`de.vvwt.tm.web.certificate.*` (controller + 2 DTOs) deleted and rebuilt under
DEC-22 Iron Law Q-1a TDD RED-first authorship at the same canonical FQNs (D-7
Coexistence Option γ), with HTTP wire contract preserved verbatim,
**so that** the certificate controller carries a trustworthy correctness oracle
and Track 2 of Epic E36 advances toward Cutover-2 with zero observable client
impact, and `CertificateRenderController` (separate concern) remains untouched.

---

## Context

Per Session Brief `discovery-2026-04-26-e36-retro-correction` D-7 Option γ:
delete-then-rebuild within feature-branch lifecycle at the same canonical FQN.
This story is the third step of Track 2 (Certificate); E36S04 completed the
certificate domain rebuild and E36S05 completed the assembler impl rebuild.

Audit `E36-discovery-legacy-inventory.md` Certificate Controller + DTOs
(E23S09) group enumerates 3 in-scope artefacts under
`de.vvwt.tm.web.certificate.*` (CertificateTemplateController, 170 LOC; 2 DTOs,
46 + 38 LOC). Audit `E36-discovery-dec41-test-classification.md` classifies the
pre-existing `CertificateTemplateControllerIT` (20 methods, count flagged 20→23
for delivery-time re-verification per Brief Q-7) as 100% Snapshot-Driven; zero
Contract Test reuse candidates.

Per Brief D-7 controller RED model + DEC-40 boundary preservation: HTTP URL
paths and JSON wire-format shapes MUST be preserved verbatim. The controller is
consumed by the Svelte UI and possibly by upload tooling; consumer expectations
are the boundary contract.

`CertificateRenderController` (E23 separate concern) is OUT-of-scope and
preserved per audit (i). It uses the `CertificateAssembler` interface (rebuilt
impl from E36S05); the interface contract is stable so the render controller
continues unchanged.

## Notes

- **Constraint** (Brief C-3): TWO DTO JSON shapes
  (`CertificateTemplateMetadataResponse`, `CertificateTemplateVariableResponse`)
  are wire contracts; field names/types/nullability MUST match legacy.
- **Risk** (Brief C-11): HTTP code mappings (e.g., 400 on invalid format/size,
  404 on unknown tournament, 401/403 on auth) are behavioral characteristics
  that MUST match legacy behavior verbatim. Some HTTP code mappings come from
  `CertificateExceptionAdvice` (still resident in this story); the rebuilt
  controller must throw the same exception types so the still-resident advice
  maps them identically.
- **Escalation triggers**: C-3 (DTO shape), C-11 (HTTP/JSON behavioral
  divergence), C-2 (consumer modifications would invalidate Option γ).
- **Method-count caveat** (Brief Q-7): Audit (ii) flagged 20→23 method count
  uncertainty. AC-METHOD-COUNT-RECONFIRMATION mandates delivery-time empirical
  verification.
- **DEC-38 application**: `@ApplicationModuleTest` boots the `web` module +
  collaborating modules; canonical IT pattern for web-tier rebuilds per DEC-38.
- **CertificateExceptionAdvice still resident**: This story does NOT delete
  `CertificateExceptionAdvice`. That deletion happens in E36S08 Phase 2.
- **Per Brief C-2**: DEC-32 invocation count remains 1 (E21S13 only).
