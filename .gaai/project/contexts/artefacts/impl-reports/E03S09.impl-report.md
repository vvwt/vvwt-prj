## Key Decisions

- **Circle method algorithm** selected for round-robin pairing (matches legacy `MatchGenerator4roundrobin`). Slot[0] is fixed; slots 1..N-1 rotate clockwise each round. For odd N, a phantom UUID (0L,0L) is added at slot N; pairings involving the phantom are dropped.
- **`createdAt` set by generator** (`LocalDateTime.now()`) rather than relying on DB DEFAULT, because Spring Data JDBC inserts explicit null when Java field is null, bypassing the DB default. This matches the pattern established in E03S05 IT helpers.
- **IT test in `de.vvwt.tm.domain.repo` package** to access package-private `TenantContext.set()` / `clear()` — same pattern as `E03S05RepositoryIT`.
- **`TournamentRepository` injected into generator** for `set_limit` derivation from `Tournament.matchFormat` via Phase.tournamentId. No eager loading of Tournament into Phase entity.
