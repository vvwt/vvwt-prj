## Implementation Summary

### Forward mapper (PhaseToRawPhaseDefMapper)
- Loads avatars and matches via tenant-scoped repositories (AC14, E03S05)
- Validates: no avatars (AC9), no matches (AC8), unknown avatar references (AC10)
- Sorts matches by UUID.toString() ascending for deterministic row order (AC7)
- Maps TeamAvatar.(groupNumber, groupPosition) → PositionTuple per DEC-9 (AC1)
- phaseId field = Math.abs(phaseId.hashCode()) — audit-only, non-negative (AC1)
- Calls StructuralFingerprint.transform(raw) for canonicalization
- Rebuilds denseId mapping (mirroring StructuralFingerprint step 1) for the applicator
- Returns MappingResult with raw, canonical, N=avatarCount, matchOrder, denseIdsByRawRow

### Slot result applicator (SlotResultApplicator)
- Unranks rank via LehmerCodec.rankToPermutation(rank, N) — N = avatarCount (AC4)
- pi[i] = "seat" assigned to avatar i in the round-robin schedule
- Builds canonical round-robin schedule via standard circle method: fix seat N-1, rotate 0..N-2
  - roundBySeat[seatA][seatB] = round number for the pair
- Assigns each match to round = roundBySeat[pi[d1]][pi[d2]] (AC4)
- Within each round: sorts by match UUID for determinism (AC7), assigns field 0..fieldCount-1
- Validates round constraint (AC5) before any DB writes
- Writes lapNumber and fieldNumber via matchRepository.save() (AC4, AC14)

### Algorithm correctness
- For N=6, fieldCount=3: produces exactly 5 rounds, 3 matches per round = 15 match slots
- Every avatar appears in exactly N-1=5 rounds (once per round — guaranteed by circle method)
- All 11 new tests pass; 183/183 total tests pass

## Known Limitations / Delivery Decisions
- The circle-method schedule requires N to be even. The implementation handles odd N by using
  N+1 virtual seats (standard bye-round extension), consistent with round-robin conventions.
- The permutation is over N avatar IDs (as specified in AC4), NOT over rowCount. This means
  the rank space is N! (not rowCount!). For N=6, the rank space is 720, which is smaller than
  the 15! row-permutation space but sufficient for the V1 exhaustive search in E04S03.
