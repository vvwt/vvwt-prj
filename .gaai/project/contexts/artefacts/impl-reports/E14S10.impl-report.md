`vvwt-tm-web/src/test/java/de/vvwt/tm/tenant/TenantContextTestSupport.java`

- Exposes a `@Bean Binder tenantContextBinder(...)` injecting `@Qualifier("tenantRoutingContext")

### Guard-fire tests — dual-unbind pattern

For IT files that assert repository guards fire when no tenant is bound
(`E03S05RepositoryIT`, `PhaseBreakRepositoryIT`, `E08S02MigrationIT`), both the new stack-based
`TenantContext` AND the legacy bridge `LOCAL_HOLDER` must be cleared before asserting the guard.
Pattern applied:

```java
tenantContextBinder.unbind();
tenantContext.clear();          // legacy bridge LOCAL_HOLDER
try {
    assertThatThrownBy(() -> repository.findAll())
            .isInstanceOf(IllegalStateException.class);
} finally {
    defaultTenantId = tenantContextBinder.bindDefaultTenant();
    tenantContext.set(defaultTenantId);   // re-bind legacy bridge for @AfterEach
}
```
