## Rules Applied

- DEC-5: All operations tenant-scoped; cross-tenant tournament → 404 (not 403)
- DEC-9: Delete blocked when TeamAvatar refs exist
- DEC-2: Svelte 5 runes mode ($props, $state, $derived) — no export let
- DEC-10: Java 21 records for DTOs; Spring Boot 4.0.5 compatible

## Notable Decisions

- **Inline save strategy (AC8):** blur/change triggers save immediately (no explicit "save all")
  — simpler UX matching legacy grid pattern
- **Bulk create best-effort (AC5):** items succeed or fail independently; caller sees per-item
  result — no atomic all-or-nothing transaction to allow partial success
- **Auto-number (AC2):** `max(existing) + 1` at request time — no reservations, no locking
  (race condition on concurrent multi-session use is acceptable for V1 single-user deployment)
