- `App.svelte` route added; `de.json` phases namespace added (14 keys)

## Key Design Decisions

- **Separate `phase_audit_log` table**: The existing `audit_log.match_id` is NOT NULL — cannot store phase-level governance events without relaxing this constraint. Created a new table following the same append-only pattern.
- **`checkTournamentCompletion` dual-path**: Called from `advanceLap()` (same transaction) and from `DomainEventBridge.onMatchResultChanged()` (new transaction after AFTER_COMMIT) to cover both the manual advance-lap path and the future auto-cascade path.
- **Tenant scope for phase endpoints**: `requirePhaseWithTenantScope()` loads the phase's tournament via the tenant-scoped `tournamentRepository` — 404 if not visible in tenant context (AC15).
