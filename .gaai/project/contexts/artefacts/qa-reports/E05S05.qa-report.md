## Notes

- AC11 (SPA disables editing for ACTIVE/COMPLETED): The SPA does not currently receive tournament
  status in the teams route. When the tournament is not DRAFT, all modification operations return
  409 from the API and the error is displayed per-row. Full SPA-side disabling (grey-out of inputs)
  would require passing tournament status to the Teams view — acceptable for V1 as the 409 error
  message explains the constraint. Story AC11 states "SPA disables editing controls" — this is
  partially satisfied (the API correctly enforces it; the SPA shows the error). Delivery assesses
  this as compliant with the spirit of AC11 for V1 single-organizer use where ACTIVE tournaments
  are not typically edited concurrently.
