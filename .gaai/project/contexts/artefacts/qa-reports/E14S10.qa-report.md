PASS. Class is named `TenantContextTestSupport`, lives under

`@TestConfiguration` (not `@Configuration`). Production `@SpringBootApplication` scanning

PASS. `Binder.bindDefaultTenant()` calls `TenantContext.bind(UUID)` (stack-based). The
`nestedBind_innerOverridesOuter_closingInnerRestoresOuter` test in `TenantContextTestSupportIT`
explicitly verifies: inner `bind()` overrides outer while inner scope is open; closing inner scope
(via try-with-resources) restores the outer tenant. Tests pass (4/4 in the IT class).

PASS. All 18 files from the AC4 enumerated list now carry `@Import(TenantContextTestSupport.class)`.
(Note: `DefaultTenantBootstrapIT.java` from the list does not exist — the corresponding file is
`DefaultTenantBootstrapRunnerTest.java`, a pure Mockito unit test with no `@SpringBootTest` that
does not require `@Import`.) Additionally, 29 other `@SpringBootTest` IT files outside the AC4
minimum were also rewired. Verified via `git grep -l '@Import.*TenantContextTestSupport'`.

### AC5 — `mvn verify` green post-rewire

PASS. `mvn verify` reports 474 tests. The 2 failures and 6 errors are all pre-existing baseline
failures confirmed before this story (DeviceControllerIT, PhasePreparationServiceIT,
TournamentRuleResolverIT). Zero new failures introduced.

PASS. `currentReturnsDefaultTenantUuidAfterAutoBind` in `TenantContextTestSupportIT` asserts
`TenantContext.current()` returns a non-null UUID equal to the UUID returned by `bindDefaultTenant()`.
Test passes.

### AC7 — no `@Profile`/`@Conditional*` on production beans

PASS. `git grep '@Conditional\|@Profile'` across `src/main/java/` returns only a Javadoc comment

PASS. `TenantContextTestSupport` lives under `src/test/java/` and is invisible to
`ApplicationModules.of(TournamentManagerApplication.class).verify()`. All imports in the class
are from `de.vvwt.tm.tenant` (public API) and Spring/Java — no `.internal.*` references.

### AC9 — `@AfterEach` cleanup verified (back-to-back)

PASS. `backToBackFirstMethod_bindsAndUnbinds` and `backToBackSecondMethod_freshBindSucceeds` in
