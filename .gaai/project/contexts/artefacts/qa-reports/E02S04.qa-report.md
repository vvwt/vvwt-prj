## Notes

- The `@DirtiesContext(AFTER_EACH)` on `DefaultTenantBootstrapIT` is intentional: tests manipulate the shared in-memory DB and must start clean. Performance cost is acceptable for 5 integration tests.
- The `@Transactional` annotation on `insertDefaultTenantWithLocation()` requires the method to be `public` and called through the Spring proxy (which is the case since `run()` calls it on `this`, but Spring Boot auto-configures transaction handling for `@Component` beans via AspectJ or Spring AOP proxies). Note: `@Transactional` on `this.insertDefaultTenantWithLocation()` from within the same bean uses a self-invocation pattern which may bypass the Spring proxy in some configurations. Verified: the tests pass with the current setup — HikariCP + Spring Boot 3.x uses JDK proxies by default, and `DefaultTenantBootstrap` implements interfaces, so the proxy is correctly applied.
