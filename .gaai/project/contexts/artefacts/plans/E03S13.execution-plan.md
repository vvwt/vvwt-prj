## Edge Cases

### AC2 (lap-advance detection)
- Happy path: `phase.currentLapNumber > event.previousLapNumber` → snapshot written
- No-advance: `phase.currentLapNumber == event.previousLapNumber` → no snapshot, no error
- Phase not found: log error, no snapshot (treated as error path per AC9/AC10)

### AC5 (UNIQUE constraint)
- Happy path: first snapshot for lap → INSERT succeeds
- Duplicate: INSERT hits UNIQUE constraint → catch `DataIntegrityViolationException`, log WARN "snapshot already exists for lap X", return (first-snapshot-wins)

### AC6 (regenerate)
- Integration test: insert snapshot, delete it, call `regenerate`, verify row re-created with same payload fields
- If `regenerate` called for non-existent lap (no matches found): log WARN, no insert

### AC9 (error isolation)
- RuntimeException in payload builder → logged at ERROR, does NOT propagate (listener is AFTER_COMMIT, cascade already committed)
- Spring AFTER_COMMIT semantics: exception in listener does not roll back committed transaction

### AC10 (DB write failure)
- `DataAccessException` on INSERT (not UNIQUE) → logged at ERROR, no retry

### AC13 (tenant scoping)
- RoundSnapshotRepository uses `TenantScopedRepository` — tenant from `TenantContext` at listener run time

## JSON Payload Schema (Delivery Decision)

```json
{
  "tournament_id": "<UUID>",
  "phase_id": "<UUID>",
  "completed_lap_number": 0,
  "captured_at": "2026-04-12T10:00:00Z",
  "team_standings": [
    {
      "rank": 1,
      "avatar_id": "<UUID>",
      "group_number": 1,
      "group_position": 1,
      "points": 3,
      "sets_won": 2,
      "sets_lost": 0,
      "balls_won": 50,
      "balls_lost": 25,
      "set_quotient": 1.7976931348623157E308,
      "ball_quotient": 2.0,
      "is_without_assessment": false
    }
  ],
  "matches_in_lap": [
    {
      "match_id": "<UUID>",
      "member_avatar_1_id": "<UUID>",
      "member_avatar_2_id": "<UUID>",
      "state": 51,
      "lap_number": 0,
      "field_number": 1,
      "referee_team_id": "<UUID or null>"
    }
  ]
}
```

Notes:
- `team_standings` sorted per D-33 (points DESC, set_quotient DESC, ball_quotient DESC, is_without_assessment last)
- `set_quotient` and `ball_quotient` use `Double.MAX_VALUE` sentinel when denominator is 0 (legacy parity)
- `referee_team_id` may be null (unassigned matches)
- No PII in payload (AC14): team names/descriptions are excluded from snapshot payload; only UUIDs
- The payload is sufficient for E08 to render standings; human-readable team names are resolved at render time from the team table
