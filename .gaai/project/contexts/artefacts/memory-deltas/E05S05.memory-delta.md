# Memory Delta — E05S05: Team management (REST + Svelte view)

## New Patterns Worth Persisting

### Pattern: Svelte 5 Runes — Route Params via $props()

In Svelte 5 runes mode (enabled by default in this project's Vite/Svelte setup), route
params from svelte-spa-router MUST be received via `$props()` syntax, not `export let`:

```svelte
interface Props { params?: { tournamentId?: string }; }
let { params = {} }: Props = $props();
const tournamentId = $derived(params.tournamentId ?? '');
```

`export let params` is illegal in runes mode and causes a build error. All future route
components must use `$props()`.

### Pattern: Inline editing with draft state

Per-row draft state stored in a Record<id, Partial<Entity>> allows tracking unsaved changes
per row without converting to a different component model. Save-on-blur for text/number inputs,
save-on-change for checkboxes. Visual dirty indicator (background + badge) informs the user.

### Pattern: Bulk create with per-item best-effort

AC5 shows the pattern: iterate items, catch ConflictException per item, accumulate results.
Returns HTTP 200 (not 201/207) with a structured per-item result list. Future bulk endpoints
should follow this pattern unless all-or-nothing semantics are explicitly required.
